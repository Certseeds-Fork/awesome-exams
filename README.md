## 📜 **Submission Guidelines 试卷上传规范**  

请遵循以下标准，上传PDF格式试卷 / Please adhere to these submission standards:

- **课程路径**：格式为`课程代码-课程名称`（如`MA127-高等数学II`）
- **试题命名**：格式为`课程代码-学年学期-考试类型.pdf`（如`MA127-2024春-期中.pdf`），学年学期与考试类型必填
